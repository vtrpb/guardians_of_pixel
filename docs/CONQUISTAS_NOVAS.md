# Vinte conquistas novas

Sem recompensas monetárias ou de combate. Cada feito desbloqueia uma vez por save. As ocultas não revelam nome nem requisito antes do desbloqueio.

## Comuns

| Conquista | Requisito |
|---|---|
| Por um pixel | Derrotar um Boss nos últimos 10% do caminho. |
| Na última hora | Vencer com o último golpe dado por uma torre construída depois que aquele inimigo passou de 90% do caminho. |
| Virada de jogo | Vencer depois de perder uma torre para um inimigo. |
| Não desta vez | Vencer na tentativa imediatamente seguinte a uma derrota na mesma fase e modo. |
| Você não passa! | Derrotar um Boss antes da metade do caminho. |
| Controle absoluto | Eliminar um inimigo com três efeitos diferentes ativos ao mesmo tempo. |
| Última linha de defesa | Vencer com todas as torres construídas na metade final do caminho, sem explosivos. |
| O verdadeiro inimigo | Perder com créditos suficientes para construir uma torre desbloqueada da equipe. |
| Era só mais uma… | Terminar três partidas, por vitória ou derrota, sem fechar ou recarregar o jogo. |
| Sem pressa | Vencer uma fase na velocidade normal do jogo. Pausas são permitidas. |

## Ocultas

| Conquista | Requisito |
|---|---|
| Cadê a saída? | Encontrar os Corredores Amarelos. |
| Amarelo demais | Escapar dos Corredores Amarelos. |
| O silêncio abre portas | Entrar no castelo do Limbo. |
| Hóspede curioso | Visitar salão, corredor do segundo andar, varanda, quarto real, quarto de hóspedes, sala de estar, biblioteca e galeria. |
| Assunto de família? | Examinar o retrato do casal. |
| Até o vazio tem limites | Falar com os guardas do arsenal. |
| Desafiando a coroa | Iniciar a primeira wave da arena. |
| Respeito conquistado | Vencer a arena do Limbo. |
| Uma promessa no vazio | Terminar a conversa da promessa de ajuda. |
| Duas respostas, dois caminhos | Concluir a conversa da verdade e entrar no castelo pela rota do silêncio no mesmo save. |

Regras técnicas, limites e persistência: ESPECIFICACAO.md, seção Vinte conquistas adicionais.
